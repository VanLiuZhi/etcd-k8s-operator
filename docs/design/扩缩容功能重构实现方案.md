## 🔄 扩缩容算法实现

### 协调循环 (reconcile)

#### 主要流程
1. **状态检查**: 比较当前状态与期望状态
2. **成员协调**: 调用`reconcileMembers()`处理成员差异
3. **扩缩容执行**: 根据需要调用`addOneMember()`或`removeOneMember()`
4. **状态更新**: 更新集群状态和条件

#### reconcileMembers算法
```go
func (c *Cluster) reconcileMembers(running etcd.MemberSet) error {
    // 1. 移除未知成员（不属于集群的Pod）
    unknownMembers := running.Diff(c.members)
    if unknownMembers.Size() > 0 {
        // 删除未知Pod
    }
    
    // 2. 计算有效运行成员
    L := running.Diff(unknownMembers)
    
    // 3. 检查状态一致性
    if L.Size() == c.members.Size() {
        return c.resize() // 执行扩缩容
    }
    
    // 4. 检查法定人数
    if L.Size() < c.members.Size()/2+1 {
        return etcd.ErrLostQuorum
    }
    
    // 5. 移除死亡成员
    return c.removeDeadMember(c.members.Diff(L).PickOne())
}
```

### 扩容实现 (addOneMember)

#### 扩容步骤
1. **设置状态**: 设置扩容条件
2. **生成成员**: 创建新的Member对象
3. **etcd添加**: 向etcd集群添加成员
4. **创建Pod**: 创建Kubernetes Pod
5. **错误处理**: 失败时回滚etcd操作
6. **事件记录**: 记录扩容事件

#### 关键代码
```go
func (c *Cluster) addOneMember() error {
    c.status.SetScalingUpCondition(c.members.Size(), c.cluster.Spec.Size)
    
    newMember := c.newMember()
    
    // 向etcd集群添加成员
    resp, err := etcd.AddMember(c.members.ClientURLs(), c.tlsConfig, []string{newMember.PeerURL()})
    if err != nil {
        return err
    }
    newMember.ID = resp.Member.ID
    c.members.Add(newMember)
    
    // 创建Pod
    if err := c.createPod(c.members, newMember, "existing"); err != nil {
        // 回滚：从etcd移除已添加的成员
        etcd.RemoveMember(c.members.ClientURLs(), c.tlsConfig, newMember.ID)
        c.members.Remove(newMember.Name)
        return err
    }
    
    return nil
}
```

### 缩容实现 (removeOneMember)

#### 缩容步骤
1. **设置状态**: 设置缩容条件
2. **选择成员**: 选择要移除的成员
3. **etcd移除**: 从etcd集群移除成员
4. **删除Pod**: 删除Kubernetes Pod
5. **清理PVC**: 删除持久化存储（如果启用）
6. **事件记录**: 记录缩容事件
